# Sources

## Rules

- Cite only what you fetched or read in this session: WebFetch, the context7 MCP tools (resolve the library id,
  then query its docs), or files in the repo. Never cite from memory, and never construct a URL you didn't open.
- Match the version the repo actually uses (lockfile or manifest) when the docs are versioned.
- Link to the section: a URL with an anchor, or the page plus the heading name. Add one line on what it says.
- Code facts are `file:line`.

## Priority

1. Official docs, specs or RFCs of the exact library, API or protocol
2. Maintainer guides and official examples
3. Established references (MDN, OWASP, the language's own docs)
4. Blog posts, only when nothing above covers it, labelled as such
