# Doc audit: claude/relaxed-newton-cr62u9 ← main

`/verify` ran this audit on 2026-10-30 on the writing-style branch (merge-base `753ba2c`; the working tree was on
`0bc4465`, with the self-review fixes). Most of the changed docs tell the truth about the code, but four places
mislead:

- The copyedit's fallback path points at a folder that doesn't exist.
- Four docs claim the copyedit keeps an edit "only when nothing was lost", although code can't see meaning.
- The copyedit procedure tells the reader to "accept" an edit that is already written.
- Flows' README introduces the writing section without the copyedit.

The other findings are smaller gaps between a doc and the code, and wording.

## Scope

The audit covers the docs the branch changed or that name what it changed: `README.md`, `CLAUDE.md`, `GLOSSARY.md`,
`THIRD_PARTY.md`, `plugins/flows/README.md`, `plugins/flows/references/flow-rules.md`,
`plugins/flows/skills/doc-audit/SKILL.md`, `plugins/flows/skills/integrate/SKILL.md`,
`plugins/flows/skills/writing/SKILL.md`, `plugins/flows/skills/writing/references/copyedit.md`,
`plugins/flows/hooks/hooks.json`, and the `description` fields of `.claude-plugin/marketplace.json` and
`plugins/flows/.claude-plugin/plugin.json`. The 14 lesson references were checked against the book separately
(flow.md, Deviations).

How each phase ran:

- **Claims:** three `flows:spec-compliance-checker` agents checked one area each: the prose hook, `compare.mjs`, and
  `flows-uses.mjs` with the pstack sync. All three returned `partial`; their gaps are findings 5 to 9.
- **CLAUDE.md:** skipped here, because `/self-review` already ran the CLAUDE.md audit.
- **Mechanics:** a script resolved every relative link and repo path in the scoped docs. It missed only paths relative
  to a skill folder (`scripts/compare.mjs`) and placeholders (`docs/audits/`), and those are correct. The one URL the
  branch adds, `https://github.com/mlwelles/technical-writing-density`, answered 200. `claude plugin validate
  plugins/flows` passed.
- **Prose:** one agent read the changed text against `flows:writing`.
